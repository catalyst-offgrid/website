# Catalyst Energy Advisors — Website Mirror

Static mirror of catalyst-advisors.com hosted on GitHub Pages.

**Live:** https://catalyst-offgrid.github.io/website/

This is a pixel-perfect mirror of the Wix-hosted site at catalyst-advisors.com, republished as static files to demonstrate free hosting. Source HTML was exported via Chrome "Save Page As → Webpage, Complete" and the asset folders are republished unmodified.

## Known limitations

- Contact form renders but does not submit (no backend in this phase).
- Some Wix analytics/tracking scripts may log harmless console errors.

## Pages

- `index.html` — Home
- `team.html` — Team
- `experience.html` — Experience
- `innovations.html` — Innovations
- `contact.html` — Contact
